# TP DevOps - Gestion de Projets & Cycle de Vie du Code

Ce dépôt regroupe les travaux pratiques du module **DevOps** (Université Abderrahmane Mira - Béjaïa).
Il implémente une application modulaire et illustre la gestion des versions avec Git :
- Gestion de branches et stratégies de fusion (`merge` et `rebase`)
- Résolution manuelle des conflits
- Collaboration via Pull Requests et simulation d'équipe
- Bonnes pratiques de versionnement (revert, stash, tags sémantiques)
- Contribution distribuée en environnement multi-développeurs

## Structure du Projet
- `app.py` : Application principale en Python
- `REPONSES_TP1.md` : Réponses détaillées aux questions de réflexion du TP
- `etudiants/` : Espace collaboratif de la promotion
